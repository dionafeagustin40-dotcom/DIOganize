BACKGROUND PICTURES
-------------------
The app already ships with built-in illustrations (the .svg files here), so every
page has a background out of the box.

Want real photos? Drop a JPG in this folder with the SAME NAME (e.g. cathedral.jpg).
A .jpg automatically shows on top of the matching .svg -- no code changes needed.

  cathedral.jpg      app background, dashboard banner, login, landing, sidebar
  baptism.jpg        Baptism card / banner
  wedding.jpg        Wedding card / banner
  funeral.jpg        Funeral Service card / banner
  confirmation.jpg   Confirmation
  communion.jpg      First Communion
  blessing.jpg       Blessing (also Announcements)
  marriageprep.jpg   Marriage Preparation

Tip: use landscape photos, about 1600px wide for cathedral.jpg and 800px for the rest.
